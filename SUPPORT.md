# Support

Applies to every repository that does not define its own.

| You have | Go to |
|---|---|
| A usage question | [Discord](https://discord.com/invite/PZqkgxu5SA) |
| A bug with a reproduction | An issue on that repository |
| A feature idea | An issue on that repository |
| A security vulnerability | [SECURITY.md](SECURITY.md), never a public issue |
| A change to contribute | [CONTRIBUTING.md](CONTRIBUTING.md) |

## Asking well

- Search existing issues first, including closed ones.
- Say what you ran, what you expected, what happened.
- Include the version, install method, OS, and runtime version.
- Paste output verbatim in a code block.
- Redact secrets first. API keys, tokens, internal hostnames, and client data do not belong in a public issue or Discord.

## What support is not

Issues are triaged when maintainers have time. No response commitment outside [SECURITY.md](SECURITY.md).

Commercial support is a separate conversation: [blacklanternsecurity.com](https://www.blacklanternsecurity.com).
