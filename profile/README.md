# Black Lantern Security

Offensive security tooling, built in the open.

## BBOT

[BBOT](https://github.com/blacklanternsecurity/bbot) is a recursive internet scanner. Modules chain, so the output of one is the input of the next. A seed domain becomes subdomains, open ports, web technologies, findings.

Its libraries stand alone:

| Project | What it does |
|---|---|
| [baddns](https://github.com/blacklanternsecurity/baddns) | Subdomain takeover and DNS misconfiguration detection |
| [blastdns](https://github.com/blacklanternsecurity/blastdns) | High-performance DNS resolution |
| [blasthttp](https://github.com/blacklanternsecurity/blasthttp) | High-performance HTTP client |
| [cloudcheck](https://github.com/blacklanternsecurity/cloudcheck) | Identifies which cloud provider owns an address |
| [radixtarget](https://github.com/blacklanternsecurity/radixtarget) | Fast IP and DNS target matching |
